# BOM: Cables and Interconnects

This bill of materials lists the cable assemblies and interconnects used to link the EsoCore Edge
board to its sensor modules. It includes M12 circular connectors, shielded twisted-pair cabling,
Ethernet patch cables, and associated strain reliefs. For wiring diagrams and pinout details,
see the [Edge Hardware](/docs/esocore-edge) documentation for integration details.
