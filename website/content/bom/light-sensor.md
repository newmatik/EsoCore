# BOM: Light Sensor

The light sensor module bill of materials includes the ambient light photodiode, transimpedance
amplifier, precision ADC, RS-485 transceiver, and supporting passive components. Parts are rated
for industrial lighting and optical presence detection applications. For specifications, see the
[Light Sensor Module](/docs/sensors/light-sensor) documentation.
