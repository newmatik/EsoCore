# BOM: Temperature Spot Sensor

The temperature spot sensor module bill of materials includes the infrared thermopile detector,
optical lens assembly, signal conditioning ADC, RS-485 transceiver, and supporting passives.
Components are selected for accurate non-contact surface temperature measurement in industrial
settings. For specifications, see the
[Temperature Spot Sensor Module](/docs/sensors/temperature-spot-sensor) documentation.
