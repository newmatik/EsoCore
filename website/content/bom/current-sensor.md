# BOM: Current Sensor

The current sensor module bill of materials includes the Hall-effect current transducer, signal
conditioning amplifier, over-voltage protection circuitry, RS-485 transceiver, and supporting
passives. Parts are rated for continuous industrial current monitoring applications. For wiring
and specifications, see the [Current Sensor Module](/docs/sensors/current-sensor) documentation.
